# 📦 KanMind Frontend

Frontend-Anwendung für **KanMind**, ein Kanban-Board zur Verwaltung von Projekten, Aufgaben und Workflows.

Das Frontend kommuniziert mit dem KanMind Backend über eine REST API und bietet eine intuitive Oberfläche zur Organisation von Boards, Listen und Aufgaben.

---

## 🚀 Features

* Benutzerfreundliche Kanban-Oberfläche
* Erstellen und Verwalten von Boards
* Aufgaben anlegen, bearbeiten und organisieren
* Kommunikation mit dem Django REST Backend
* Responsive Benutzeroberfläche

---

## 🛠️ Technologien

* HTML
* CSS
* JavaScript (Vanilla JS)

---

## 📋 Voraussetzungen

Für die vollständige Nutzung wird das KanMind Backend benötigt:

* KanMind Backend API
* Laufender lokaler oder produktiver Backend-Server

---

## ▶️ Lokale Entwicklung

Projekt klonen:

```bash
git clone https://github.com/NicoMeyerDev/kanmind-frontend.git
```

Projektordner öffnen:

```bash
cd kanmind-frontend
```

Anschließend die `index.html` mit einem lokalen Webserver starten (z. B. VS Code Live Server).

## 🎯 Projektziel

KanMind wurde entwickelt, um Projekte, Aufgaben und Workflows übersichtlich in einer Kanban-Struktur zu organisieren und gleichzeitig praktische Erfahrungen in der Entwicklung moderner Webanwendungen mit Frontend und Backend zu sammeln.
